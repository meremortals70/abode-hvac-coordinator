# D044

Power management fails open: any missing figure means no ceiling.

Status: in force. Cited in the specification and the code by `[D044]`.

An outdoor unit whose draw is not yet learned sets no ceiling either. It keeps going until the battery is down to its reserve, when a running Enforced room is turned off, or the window ends at the tariff change: running is the only way its draw is learned (Jason, 6 November 2026) [D063].
