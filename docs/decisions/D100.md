# D100

The unit's lowest steady rate, U_min, is learned only from a 30-minute run held at or below the lowest rate the plan offered at the time.

A run held above that rate shows only that the unit can run there, not how low it can go. Before this, the first long run at full rate, the usual pull-down on a hot afternoon, became U_min, and the plan could then only rest or cool at full rate until a lower rate happened to be held for 30 minutes. Before anything is learned, the lowest rate offered is the rate at the first point of the learned curve. A minute with no effort asked (the room at or past the setpoint while the compressor runs) is no rate held and breaks the run, so U_min is never learned as 0; a stored 0 is relearned. A hold at or below the lowest rate offered replaces U_min, up or down, since the curve it is read from moves as it is learned; and the lowest rate offered is never below the curve's first point, which no effort asks for less than. Heating and cooling each keep their own U_min, on their own curves; a change of direction starts a new run.
