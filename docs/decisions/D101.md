# D101

Off or fan-only is not running. In any other mode the component watches the house power: a rise is the compressor starting, a fall back is it stopping (Jason; built 8 November 2026).

This is how the compressor of a unit that reports neither its frequency nor `hvac_action` is known (4.8, source 3). What counts as a rise is half the unit's learned draw, never under three times the house power's own noise, learned from its readings. An inverter slowing near its setpoint is not a stop: only a fall back to where the power stood with the compressor stopped is. Draw is learned from the same starts and stops (D028).

Status: in force. Cited in the code by `[D101]`.
