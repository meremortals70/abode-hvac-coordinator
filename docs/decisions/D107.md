# D107

The mode sensor says which grace the room is in, not the answer the grace is
holding.

An occupancy grace is a wait: the room is not yet the thing, so the old
answer stands. Before this, the mode sensor showed that old answer, so a room
re-occupying read `unoccupied` for the occupied grace (2 minutes by default)
and one emptying read `occupied` for the empty grace. The office on
13 November read `unoccupied` for two minutes every time someone walked back
in, and the user set it to manual each time, believing the room was stuck.

The sensor now names the grace:

- `occupied_grace` — presence has read occupied but not yet for the occupied
  grace;
- `empty_grace` — presence has read empty but not yet for the empty grace;
- `opening_grace` — a door or window is open and the unit is still inside the
  opening grace, before it is stopped.

Leave and Precool are deliberate and keep their own states. The state is a
label only: the band rule, the plan and the unit's behaviour are unchanged.

The occupancy waits are also named `occupied_grace` and `empty_grace` in the
settings (formerly `occupied_after` and `empty_after`), so all four waits —
these two, `warning_grace` and `opening_grace` — read as one family. A room
saved under the old keys is read once through them, and the new keys written
from the next save.

Status: in force. Cited in the code by `[D107]`.
