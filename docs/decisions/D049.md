# D049

Automatic control off stops the automation, and the room's controls are then the user's. Automatic vane control decides whether the component moves the vertical vane.

**A control with nothing to mirror says what the room is being held at.** The
setpoint control shows the unit's live value, but a unit that is resting — fan
only, or off — reports none, and the control then went blank while the component
was holding the room at a setpoint. On 24 November 2026 the office's page showed
an empty setpoint with the room 1.1 points above its band. While Automatic
control is on, and only while a step is still holding the room, the control shows
the setpoint last sent — the one the component's own step put there, kept with
the room so a restart does not lose it. It is not shown while the room is being
stopped (Leave, an empty room, a door left open) or after a failed cycle, because
there is then no setpoint the room is being held at; and it is cleared when the
user takes charge, so a hand-back never shows a value from before the manual
spell. The room's own hold is in °C, so it is shown even in a house whose
temperature unit the integration cannot convert the unit's value from. When the
user is in charge the blank stays.

Status: in force. Cited in the specification and the code by `[D049]`.
