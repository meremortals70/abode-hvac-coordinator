# D106

The plan starts its forecast from the room the band rule measures.

The forecast's opening comfort index is built from the **measured** vapour
pressure (`e_now`, the same reading `comfort.room_index` uses) and the
measured temperature, not from the moisture filter's own estimate. The two
can differ: a filter still settling on a room, or one whose figures were
learned against a short-cycling unit it could not see. Where the filter's
estimate sits below the reading, the plan reads the room inside its band
while the room is above it, and rests.

A reading always says where the room is [D074], and the band rule already
measures the room from it [D055]. The plan must forecast the same room, or
it optimises a room the user is not in. The moisture filter still supplies
the figures the forecast moves the moisture with; only the starting point is
the reading.

Status: in force. Cited in the code by `[D106]`.
