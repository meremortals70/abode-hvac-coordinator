# D098

An edit keeps what each of the room's modules remembers between cycles, and makes the room's entities again from the new settings.

What is kept: the running command the short-cycle guard holds a stop on, today's scorecard, the plan and controllers, the band's ramp, warnings already given, commands still to be reported. What the room no longer has (a head, a reading) is forgotten. The entities are taken out and made again, so the set a room has and the units its controls follow match its settings; registry entries stay, and that of an entity the room no longer has is removed.

Status: in force. Cited in the code by `[D098]`.
