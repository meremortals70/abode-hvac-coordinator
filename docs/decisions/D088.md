# D088

Each room has a Leave button. It turns the room off at once, not held by the minimum run, until someone comes back. A room without a presence sensor cannot see anyone come back: it stays off until the user changes Automatic control or Comfort mode, or asks for Precool (Jason, 6 November 2026: "Leave, that is correct").

Status: in force. Cited in the specification and the code by `[D088]`.
